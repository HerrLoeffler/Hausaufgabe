    So funktioniert Test-Rallye

    Die Lehrkraft startet für alle. Bearbeite jede Aufgabe in Ruhe und klicke erst dann auf „Antwort prüfen“. Einzelne Klicks werden nicht bewertet.

    • Voll richtig: +100 Punkte.
    • Teilweise richtig: anteilige Punkte, ohne Pause. Falsche zusätzliche Markierungen können richtige Teile aufheben.
    • Automatisch vollständig falsch: −50 Punkte, mindestens 0 Gesamtpunkte, dann 5 Sekunden Antwortpause.
    • „Weiß nicht“: 0 Punkte und dieselbe 5-Sekunden-Pause.
    • Nach der Pause kommt automatisch die nächste Aufgabe. Es gibt einen Versuch pro Aufgabe.
    • Bei Verbindungsfehlern bleibt die Abgabe erhalten und wird sicher erneut versucht. Das gibt keine zusätzliche Strafe.
