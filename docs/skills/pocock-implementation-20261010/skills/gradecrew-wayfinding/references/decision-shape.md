# Compact decision section

Destination: one agreed result. Task/owner/role: existing identity. Sources: exact refs and time; live task/release truth stays in the established files.

| Decision | Type | Prerequisites | Owner | Evidence / resolution |
| --- | --- | --- | --- | --- |
| existing-task.D1 — readable question | fact / preference / prototype | actual IDs or none | existing owner | source + unresolved, or real answer |

Frontier: ready decisions with no unresolved prerequisites; identify permission/tool limitations separately. Blocked: decision → unresolved prerequisite. Unknowns: not yet precise enough. Excluded: outside destination. Preference prompt for Root: concrete options, tradeoff and why current evidence cannot choose. Do not publish it as Martin's answer.

Stop at the agreed outcome. This is a planning index, not a new release status or dispatch queue.
