# GradeCrew decision frontier

Read current GradeCrew entry rules and the existing task handoff. Name the role, task owner and exact source SHA. Coordinators may research/brief through permitted APIs; only an authorized specialist may write an artifact or run a probe. Notes, an assignee or this skill grant no execution rights and provide no atomic lock. Keep existing tasks, history, budgets and recovery evidence.

If the next step is already clear, use the existing plan and end wayfinding. Otherwise define one small destination. Keep a bounded decision section in the owned task handoff, or link one already authorized decision artifact; do not create a parallel task/release database or an issue hierarchy by default. Use the [compact shape](references/decision-shape.md).

Start with at most four precise questions. Each has a readable name/ID, fact-versus-preference type, actual prerequisite IDs, owner, evidence pointer and resolution. Unphraseable in-scope questions stay in a short unknowns line; excluded work never silently enters the frontier. A decision is ready only when its prerequisites have actual resolutions and its owner is free to act.

Investigate ready factual questions with available repository/primary-source tools. Read sources before relying on captions or old agent reports; distinguish current code, historical claims and missing evidence. Do not invent a research/grilling/domain-modeling tool or install a tracker. Available Superpowers brainstorming/planning may help; otherwise name the direct primary-source/briefing method used.

Prepare genuine product choices with concrete options and tradeoffs for Martin through the authorized coordinating route. Existing human decisions are evidence, not questions to ask again. Await a real answer before closing a preference. Prototypes use the target runtime when the question concerns its interaction.

Record the smallest resolution with its source once; retain links rather than duplicating answers. Recompute ready/blocked questions after an answer. At the destination, hand off decisions, remaining unknowns and exactly one next authorized step. Do not turn planning into deployment or reset attempts. Apply current adaptive effort rules; requested/observed model and unknown usage remain separate.
