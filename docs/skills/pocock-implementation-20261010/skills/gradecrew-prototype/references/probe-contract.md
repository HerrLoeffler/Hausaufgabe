# Minimal probe record

Existing task/role/owner and exact source/build. Question and excluded work. One slice or two relevant alternatives. Start state and owned test process/window/slot. User actions and observable effects. Existing harness and necessary invariants. Evidence pointer with performed vs pending checks. Human verdict or pending question via Root. Time/correction stop, only owned cleanup, exactly next authorized step.

For a native question the record identifies the native engine and runtime prerequisite; an HTML mock cannot resolve it. A sandboxed save variant never writes the normal user slot, changes save version or jumps locked progression. Never promote a prototype merely because its demonstration is attractive.
