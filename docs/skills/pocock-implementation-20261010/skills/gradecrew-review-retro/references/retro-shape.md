# Bounded retrospective

Observation with source/run/time → effect/needed rework → existing mechanism inspected → mechanical check candidate or judgment rule → actual owner/scope → acceptance for a fix.

At most three observations, ranked by concrete effect. End with one selected candidate or prepared owner question. A suggestion is not an installed guard. Read the existing lint/type/test/CI entry before adding anything; unavailable source stays a limit. Do not turn missing credentials, tool dependencies or truncated output into a model-upgrade or global rewrite. Preserve task, attempts, evidence and budgets; no claimed cost saving without measurements.
